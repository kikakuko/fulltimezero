## 2. 화면 — 사용자가 지나는 길

```
문 셋 (처음 한 번)     나는 멈추었다 → 무엇이 움직이는가 → 한 번도 움직인 적 없다
                        현판 일주문 · 천왕문 · 불이문. 둘째 문 양옆에 사천왕 둘
                        그림 한 장 위의 장막. 그림은 움직이지 않는다.
매일의 문              앱을 열 때 첫째 문의 빛이 짧게 온다 (설정 「앱을 열 때 빛이 온다」에서 끈다)

오늘    달 · 오늘 쉬었는가 · 쉬었다 → 쉼 기록 · 앉는다 → 앉기
        오늘을 비워 둔다 (손짓 안의 떨림, 종성은 기본 꺼짐) — 누르면 땅이 울리고 미륵이
        솟는 넉 초의 장면. 하루 한 번. 한 줄은 처음 비운 날과 다 올라온 날에만
        쉼의 안내로 가는 길. 계절의 인사와 바쁜 저녁의 한마디 (이레에 한두 번)
날들    달력 하나 — 먹점(일정) · 옅은 원(비움) · 또렷한 날짜(고요했던 날)
        달력 위의 미륵 — 미륵당 마당에 묻혀 있고, 비운 날만큼 드러나 있다(스물넷이면 가슴까지)
        하루 화면 — 일정 한 줄, 쉼과 앉음 지우기, 이 날을 비워 둔다
앉기    코끼리의 길 (청록 산수) — 앉은 흔적. 코끼리는 부위별 SVG 로 걷고, 아홉째(등지)
        에서는 걸음을 멈추고 온전히 선다. 흩어짐은 무위에만. 정거장 아홉은 지명
        앉는다 (길이 · 종성 · 자리 고르기) / 아무것도 하지 않는다 — 같은 무게
사경    하루 한 자. 올리면 글씨가 탑으로 날아가 앉는 장면. 탑은 언제든 본다
쉼의 안내  여섯 장. 여섯째는 아홉 자리 — 흩어 놓은 돌
설정    언어 · 시간대 · 매일의 문 · 비울 때의 종성 · 내보내기 · 나가기 · 계정 지우기
```

몰입 화면(앉는 중 · 무위 · 문 셋 · 몫이 끝난 자리)에는 자리 넷도 언어 전환도
없다. 어둠은 그 화면들의 것이다.

## 3. 모델

| 모델 | 무엇 | 사용자의 것 |
|---|---|---|
| `User` | 계정. 이메일 · 언어 · 시간대 · 두 설정 · 온보딩 시각 · 둘째 문의 한 줄(`what_moves`) | ○ |
| `Rest` | 쉼 기록 — 날짜 · 길이(다섯 중 하나) · 결 | ○ |
| `Sitting` | 앉음 — 날짜 · mode(sitting/nothing) · 끝난 시각 · 고른 자리. 길이는 저장하지 않는다 | ○ |
| `Plan` `Clearing` | 일정 한 줄 · 비워 둔 날 | ○ |
| `Copying` | 사경 한 자 — 날짜 · 경의 글자 · 붓 획(비율 좌표) | ○ |
| `Sutra` `SutraPhrase` `SutraChar` | 반야심경 이백예순 자. `data/heart_sutra.yml` | 앱의 것 |
| `Abiding` | 아홉 자리. `data/nine_abidings.yml` | 앱의 것 |
| `MoonPhase` `Calendar` `Elephant` `Maitreya` `Pagoda` `PagodaLayout` `Greeting` `Evening` | 계산. 저장하지 않는다 | — |
| `SilenceGate` | 소리와 편지의 문. `KINDS` 의 `unsolicited` 는 비어 있다 | — |
| `Export` | 사용자의 것을 통째로. `SECTIONS` 가 `has_many` 와 같아야 한다 | — |

「사용자의 것」은 `Export` 에 빠짐없이 담기고, 계정을 지우면 즉시 · 완전히 사라진다.

## 4. 확정된 규칙 (되물을 필요 없는 것)

- **숫자를 화면에 두지 않는다.** 예외는 달력의 날짜뿐(`.date` 안). 그 밖의 수는 글자로.
- **달은 언제나 차오른다.** 「기운다」는 말이 코드에도 문서에도 없다.
- **쌓인 것은 무너지지 않는다.** 앱이 무너뜨리지 않는다는 뜻이다. 사용자가 제 손으로
  선언을 거두는 것은 다르다(비움을 거두면 미륵은 그만큼 내려간다).
- **코끼리는 흔적, 아홉 자리는 안내.** 둘을 잇는 코드는 없고, 생기면 깨진다.
- **주사는 하루 한 번 — 오늘 쓴 한 자.** 주사(朱砂, --cinnabar)는 탑 안의 오늘 쓴 한 자에만
  쓴다. 어제까지의 글씨는 먹이고, 날이 바뀌면 오늘의 주사도 먹으로 마른다. 탑 자체는
  석간주(石間硃, --seokganju-*)로 칠한다 — 건물의 색이라 다른 물감이고 §2 와 상관없다.
  버튼 · 링크 · 오류 · 테두리에는 어느 붉은색도 쓰지 않는다.
- **색은 `:root` 한 곳.** 그림(SVG)에도 색이 없다. 기기의 다크 모드를 따르지 않는다.
- **어둠은 문의 것.** 문 셋과 몰입 화면만 어둡다.
- **도상은 말하지 않는다 — 움직이지 않는다는 뜻이 아니다(§2).** 도상은 제 일을
  한다: 코끼리는 걷고, 달은 차고, 미륵은 솟고, 탑은 쌓인다. 다만 어느 것도
  사용자를 부르거나 말을 걸거나 표정으로 조르지 않는다. 「도상은 움직이지
  않는다」는 헌법에 없는 말이다(2026-09-17 바로잡음).
- **그림은 움직이지 않는다 — 문 셋에서만.** 문 셋의 그림(사천왕 포함)은
  그대로이고 빛과 장막만 움직인다. 다른 화면의 도상에는 해당하지 않는다.
- **종성은 사용자가 켜고 누르는 소리.** 밤에도 울린다 — 유일하게.
- **언어는 둘.** 셋째 언어는 문장이 굳은 뒤에 그 언어로 쓰는 사람이 쓴다. 기계 번역 없음.
  손댈 곳: `config/application.rb` 의 목록, 로케일 파일, `CopyLocks::WORDS`, 데이터의 `*_<언어>` 칸.
- **옛글의 낱말은 옛글의 것.** 육력 · 사작의의 이름은 가르침의 자물쇠 밖이다(§5의 적용).
- **바깥을 부르지 않는다.** 웹폰트도, 분석도, 미리 연결도. 링크는 요청이 아니다.
