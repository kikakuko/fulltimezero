# M4 설계 — 一字一心

> This app is a raft. — 이 앱도 뗏목이다.
> 근거: [SPIRIT.md](../SPIRIT.md) · 앞선 마일스톤: [M3-design.md](M3-design.md)

## 1. 한 문장

반야심경 이백육십 자를 **하루에 한 자씩** 만난다. 그날의 한 자를
보고 나면 그날 몫은 끝나고, 다음 자는 내일 온다.

배우는 것이 목표가 아니다. 하루에 한 번, 한 글자 앞에 잠깐 서 보는
것이 전부다. 다 못 외워도 아무 일이 없고, 다 외워도 아무 일이 없다.

## 2. 승인이 필요한 두 갈래 (요청하신 것)

### ① 숫자 없이 진도를 보이는 법 — 「경면(經面)」

이 앱에는 이미 답의 형태가 있다. 「달의 자취」가 스물여드레를
점으로 보였듯, 경전은 **경전 자신으로** 진도를 보인다.

```
┌─────────────────────────────────────┐
│  경면                                │
│                                     │
│  觀 自 在 菩 薩 行 深 般 若 波 羅 蜜   │  ← 지나온 자: 먹빛
│  多 時 照 見 五 蘊 皆 空 度 一 切 苦   │
│  厄 舍 利 子 色 不 異 空 空 不 異 色   │
│  色 即 是 空 空 即 是 色 受 想 行 識   │  ← 오늘 자: 한 겹 진하게
│  亦 復 如 是 舍 利 子 是 諸 法 空 相   │
│  不 生 不 滅 不 垢 不 淨 不 增 不 減   │  ← 아직 오지 않은 자: 아주 옅게
│  ⋮                                   │
│                                     │
│  지나온 자리.                         │
└─────────────────────────────────────┘
```

- 이백육십 자가 처음부터 **전부 거기 있다.** 옅은 잿빛으로.
  지나온 자만 먹빛이 되고, 오늘 자는 그 경계에 한 겹 진하게 선다.
- 화면에는 숫자가 없다. 몇 자를 지났는지, 몇 자가 남았는지,
  몇 퍼센트인지 어디에도 쓰지 않는다. **경면이 곧 눈금이다.**
- 이것은 달의 문법과 같다: 달이 차오르듯 경면이 짙어진다.
  긴 호흡(스물여드레)과 더 긴 호흡(이백육십 날)이 같은 방향을 본다.
- 카피는 「지나온 자리.」 한 줄. 「스물여드레」의 자리와 같은 어법이다.
- **연속기록이 아니다.** 하루 빠뜨려도 끊기지 않는다. 경면은
  날짜가 아니라 만난 자를 세므로, 사흘을 쉬었다 와도 다음 자가
  기다리고 있을 뿐이다. 만회를 권하지 않고, 밀린 자를 몰아 보여
  주지도 않는다 — 하루 몫은 언제나 한 자다(제2·6조).

### ② 잠금의 기준 시각 — 스물여드레 창과 같은 규칙

**하나의 규칙만 쓴다: `user.today`.**

이 앱에는 이미 하루의 경계가 하나 있다 — 사용자 시간대 기준
자정이다. 쉼 기록의 `rested_on`, 앉음의 `sat_on`, 달의 스물여드레
창, 일정의 하루가 모두 그것을 쓴다. 一字一心도 같은 것을 쓴다.

```ruby
# app/models/user.rb — 이미 있는 것
def today = Time.current.in_time_zone(time_zone).to_date
```

- 그날의 한 자를 보았는가는 `readings.exists?(read_on: user.today)` 다.
- 다음 자는 **사용자의 자정에** 열린다. 서버의 자정도, UTC 의
  자정도 아니다. 서울의 사용자와 뉴욕의 사용자에게 각자의 밤이 있다.
- 시간대를 바꾸면 경계도 따라 움직인다. 이미 본 자를 되무르지
  않고, 앞당겨진 자정에 다음 자가 열릴 뿐이다 — 되돌리는 처벌을
  만들지 않는다.
- 잠금은 문을 잠그는 것이 아니라 **다음 자를 내주지 않는 것**이다.
  오늘 본 자는 하루 내내 다시 볼 수 있다. 복습은 조름이 아니다.

`test/models/reading_test.rb` 가 시간대가 다른 두 사용자에게 경계가
각자 맞는지, 자정을 넘기면 다음 자가 열리는지 검사한다.

## 3. 화면

### (1) 오늘의 한 자 — `/ko/glyphs/today`

```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│               空                     │   아주 크게. 명조
│                                     │
│            빌 공                     │   훈음
│                                     │
│        empty · emptiness            │   영어 뜻
│                                     │
│           반야심경                    │   출처 한 줄
│                                     │
│           경면 보기                   │   작게
└─────────────────────────────────────┘
```

한 자와 그 자의 이름뿐이다. 풀이도 해설도 없다. 「이 자는 …을
뜻하며 …에서 유래하여」로 시작하는 문단을 두지 않는다 — 그것은
공부지 쉼이 아니다.

### (2) 오늘 몫 끝 — 그 자를 보고 나면

```
┌─────────────────────────────────────┐
│               空                     │
│                                     │
│        오늘 몫은 끝났다. 이제 쉬어라.  │
└─────────────────────────────────────┘
```

M1 부터 써 온 그 문장을 그대로 쓴다. 다음 자로 가는 고리가 없다.

### (3) 경면 — `/ko/glyphs`

위 ①의 그림. 지나온 자를 눌러 다시 볼 수 있다(복습). 아직 오지
않은 자는 눌리지 않는다 — 미리 보기는 하루 몫을 무너뜨린다.

## 4. 데이터

```
Glyph                   ← 경전의 한 자. 사용자 것이 아니라 앱의 것이다.
  position:integer      (하나부터 이백육십까지. 화면에 나오지 않는다)
  character:string      (한 자)
  sound:string          (음 — 공)
  gloss:string          (훈 — 빌)
  en:string             (영어 뜻 — empty, emptiness)
  unique index [position]

Reading                 ← 그 자를 만난 날
  user
  glyph
  read_on:date          ← user.today
  unique index [user_id, glyph_id]
  index [user_id, read_on]
```

- `Reading` 에 평가·점수·암기 여부·정답률 컬럼을 두지 않는다(제3조).
  외웠는지 묻지 않으므로 답도 없다. `reading_test` 가 컬럼 목록을
  통째로 못박는다.
- 오늘의 자 = 아직 만나지 않은 것 중 가장 앞. 만남의 수가 곧
  자리이지만, 그 수는 화면에 나오지 않는다.
- `Glyph` 은 씨앗 데이터다. 사용자를 지워도 남고, 사용자 데이터
  내보내기에는 `Reading` 만 들어간다.

## 5. 원문과 출처

- 반야심경 한문 원문(이백육십 자)은 저작권이 소멸한 공유 저작물이다.
  **글자를 대조한 URL 과 확인 일자를 `docs/SOURCES.md` 에 남긴 뒤에만**
  씨앗으로 들인다. 지금까지의 규약과 같다.
- **훈음과 영어 뜻은 자체 집필한다.** 특정 사전의 문구를 옮기지
  않는다 — 사전 표제·뜻풀이에는 저작권이 있을 수 있다. 한 자에
  한두 낱말이면 족하므로 옮겨 올 이유도 없다.
- 한글 번역문은 넣지 않는다. 현대 한글 번역본에는 저작권이 있고,
  이 앱은 경을 해설하지 않는다.

## 6. 문은 다섯이 되는가

지금 화면 아래 문은 넷이다 — 오늘 · 달의 자취 · 일정 · 안내.
一字一心은 매일 들르는 자리이므로 문이 필요하다.

**제안: 문을 다섯으로 늘린다**(오늘 · 달의 자취 · 일정 · 한 자 · 안내).
좁은 화면에서 조금 빽빽해지지만, 문 없는 기능은 없는 기능이라는
것을 「쉼의 안내」에서 이미 확인했다. 대안은 오늘 화면 안에 자리를
두는 것인데, 그러면 오늘 화면의 「행동은 하나」 원칙이 흐려진다.

## 8. 완료 기준

1. 하루 한 자 → 오늘 몫 끝 → 다음 자는 내일. 미리 볼 수 없다.
2. 경면이 짙어지는 것 말고 진도를 알리는 장치가 없다.
3. 화면 어디에도 숫자가 없다(달력 날짜 예외는 여기에 해당 없음).
4. 시간대가 다른 두 사용자에게 자정이 각자 맞는다.
5. 하루를 빠뜨려도 끊기지 않고, 만회를 권하지 않는다.
6. 알림 0건, 제3자 요청 0건.
7. `spirit_test` 를 포함한 전 테스트 통과.
