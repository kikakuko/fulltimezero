# 기준선 — 개편 전, 사용자가 할 수 있는 일

> This app is a raft. — 이 앱도 뗏목이다.
> 적은 날: 2026-09-15 · 커밋 `b9f9196` 기준 (1단계와 SPIRIT 개정 반영)

개편을 시작하기 전, 사용자가 실제로 할 수 있는 동작을 화면 단위로
적어 둔다. 무엇을 바꾸고 무엇을 그대로 둘지 줄 단위로 가르기 위한
기준선이다. `bin/rails routes`, `app/models`, `app/controllers`,
`db/schema.rb`, SPIRIT.md, M1~M4 설계를 대조해 만들었다.

각 줄은 (1) 사용자가 하는 행동 (2) 앱이 하는 반응 (3) 저장되는 데이터
(4) 근거가 되는 SPIRIT.md 조항이다. **M4(一字一心)는 설계만 있고
구현되지 않아서 표에 없다.**

## 표를 만들다 드러난 어긋남 — 1단계에서 정리됨

처음 표를 만들 때 코드와 약속이 맞지 않는 곳이 넷 있었다.
1단계(`5e42737`)에서 정리했다.

| 어긋남 | 정리 |
|---|---|
| 로그인할 때마다 `sessions`에 IP와 브라우저 정보를 저장했다. 개인정보 처리방침의 「이메일 하나만 받는다」가 거짓이었다 | 저장을 멈추고 칸을 걷어냈다. 시도 제한은 이메일(의 지문)로 센다 |
| 쉼 기록과 앉음을 한 줄도 지울 수 없었다 | 하루 화면에서 한 번 묻고 지운다 |
| 내보내기에 세션 기록이 빠져 「통째로」가 아니었다 | 세션에 사용자 말고 아무것도 남지 않게 되어 저절로 풀렸다 |
| 빈 줄로 일정을 적으면 아무 말 없이 되돌아왔다 | 한 줄로 까닭을 말한다 |

아직 남은 것: `rests.note` 는 칸과 검증(이백 자)과 내보내기가 모두
있는데, 기록 화면에 입력 칸이 없어 사용자가 쓸 수 없다.
