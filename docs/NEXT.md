## 1. 청한 알림 — 「쉼」 한 글자

헌법이 허락하는 유일한 리텐션 장치인데 아직 만들지 않았다. 침묵 게이트의
기준은 「부르지 않았는데 오는 것만이 알림」이다 — 사용자가 직접 켠 알림은
사용자가 부른 것이다.

- **알림 내용은 「쉼」 한 글자. 그것뿐이다.**
  - 한 글자면 부를 수가 없다. 「사경할 시간입니다」도 「저녁이다」도 결국
    앱이 말을 거는 것이지만, 「쉼」은 명령도 안내도 아니고 한 글자가 놓인
    것이다.
  - 언어를 늘려도 번역할 것이 없다. 영어 rest, 일본어 休. 한 글자 규칙만
    지킨다.
- 사용자가 켜야 켜진다. 기본은 꺼짐.
- 시각은 사용자가 정한다. 하루 한 번까지.
- 끊겨도 아무 일 없다. 며칠 안 열어도 다시 조르지 않는다.
- 알림을 몇 번 받았는지, 눌렀는지 세지 않는다.
- 웹 푸시라 iOS 는 홈 화면에 추가해야 온다. 그 안내를 설정에 한 줄로.

## 2. 코끼리를 부위별로 — 걸음 · 색 · 흩어짐이 한꺼번에 풀린다

지금 `elephant.png` 가 통짜라 다리가 움직이지 않는다. 길 위에 있는데 걷지
않고 제자리에서 흔들리기만 한다. 부위별 SVG 가 오면(사용자가 준비한다)
이렇게 바꾼다.

- **구조:** body / head / trunk / tusk / leg-fl / leg-fr / leg-bl / leg-br / tail
- **걸음:** 다리 넷이 transform-origin 을 어깨 · 엉덩이에 두고 ±8도로 회전한다.
  대각선끼리 같은 위상(앞왼 + 뒤오 / 앞오 + 뒤왼), 0.8초 주기. 몸통은
  translateY 0 ↔ −2px 로 절반 주기. 코는 걸음에 맞춰 아주 살짝 흔들린다
  (±3도, 1.6초).
- **색:** 부위마다 밝기를 따로 건다. 몸통이 먼저 밝아지고 머리 · 다리가
  따라오면 더 자연스럽다. 상아는 늘 흰색.
- **흩어짐(무위):** 통짜를 조각내면 격자가 생긴다. 부위별로 흩어지게 바꾼다 —
  꼬리부터 코까지 차례로, 각 부위가 제 모양을 지닌 채 떠올라 흐려진다.
- **실제 이동:** 흰빛이 바뀔 때 곡선 위를 1초에 걸쳐 가는데, 그동안 걸음이
  계속되어야 한다. 지금은 미끄러지듯 간다.

도상은 말하지 않는다 — 걷는 것은 말하는 것이 아니다(STATUS 의 확정된 규칙).

## 3. 하루의 때를 그림에

첫째 문의 빛 색(새벽 · 낮 · 저녁 · 밤, `GateLight`)을 경내와 미륵당 그림에도
CSS 필터로. 같은 그림인데 아침과 저녁이 다르게 보인다. 새 그림은 필요 없다.

## 4. 그림 파일 정리

PNG 아홉 장, 큰 것은 1.4MB 다. 화면이 늦게 뜨면 어떤 움직임도 살아나지 않는다.

## 5. 배경에 아주 작은 움직임 하나씩

경내의 연기 한 줄, 산수의 구름 하나, 미륵당의 아지랑이. 20초 주기 이상으로
아주 느리게. 여럿이 움직이면 시끄럽고, 하나만 움직이면 고요한데 살아 있다.
