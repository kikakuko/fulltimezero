# M2 설계 — 명상 타이머 · 무위의 시간 · 침묵 게이트

> This app is a raft. — 이 앱도 뗏목이다.
> 근거: [SPIRIT.md](../SPIRIT.md) · 앞선 마일스톤: [M1-design.md](M1-design.md)

## 1. 범위

포함: 침묵 게이트(단일 모듈·우회 불가), 명상 타이머, 무위의 시간,
종성(鐘聲), 앉음이 달을 채우는 규칙, 「쉼의 안내」 2·5장의 연결.

제외: 빈 일정 스케줄러(M3), 一字一心(M4), 화두·내보내기·PWA 마감(M5).
M1과 같이 **이 마일스톤에서도 앱이 먼저 보내는 알림은 하나도 없다.**
게이트는 보내기 위해서가 아니라 **막기 위해** 먼저 세운다.

## 2. 침묵 게이트 (제4조)

기능이 늘어난 뒤에 게이트를 세우면 이미 늦다. 소리와 메일이 아직
둘뿐인 지금 세운다.

### 2.1 유일한 기준

> **부르지 않았는데 오는 것만이 알림이다.**

| 갈래 | 뜻 | 게이트 판정 |
|---|---|---|
| `solicited` | 사용자가 방금 청한 응답 | 통과. 야간에도 통과 |
| `unsolicited` | 앱이 먼저 거는 말 | **언제나 차단.** 예외 경로 없음 |

비밀번호 재설정 편지는 `solicited`다 — 사용자의 물음에 대한 답이지
앱의 말 걸기가 아니다(SPIRIT 제4조 주석). 종성도 `solicited`다 —
사용자가 그 자리에서 켜고 시작한 소리다.

`unsolicited` 목록은 **비어 있다.** 앞으로도 비어 있는 것이 목표다.
목록에 무언가를 넣으려면 SPIRIT.md 개정이 먼저다.

### 2.2 모듈

```ruby
# app/models/silence_gate.rb
SilenceGate.allow?(kind, user:, at: Time.current)   # → true | false
SilenceGate.deliver(kind, user:) { ... }            # 통과할 때만 블록 실행
```

`kind` 는 게이트가 아는 이름만 받는다. 모르는 이름은 `ArgumentError` —
등록되지 않은 발신은 "조용히 통과"가 아니라 **터진다.**

```
KINDS = {
  password_reset: :solicited,   # 사용자가 청한 편지
  bell:           :solicited,   # 종성
}
```

### 2.3 침묵의 시각

야간·앉는 중·무위 중에는 **종성 외 일체 무음**이다.

```
야간   = 사용자 시간대 기준 22:00 – 07:00
앉는 중 = 끝나지 않은 Sitting 이 있다
```

`solicited` 라도 종성이 아닌 소리는 이 시각에 나가지 않는다.
(지금 소리는 종성뿐이므로 실효 규칙은 "언제나 종성뿐"이다.
규칙을 먼저 두는 이유는 소리가 하나 더 생기는 날을 위해서다.)

### 2.4 우회 불가의 강제

문서로만 막지 않는다. 세 겹으로 막는다.

1. **인터셉터** — `SilenceGate::Interceptor` 를 ActionMailer 에 등록한다.
   게이트가 찍은 표식이 없는 메일은 발송 직전에 `SilenceGate::Bypass`
   예외로 죽는다. 표식은 발송 전에 헤더에서 지운다.
2. **소스 검사 테스트** — `deliver_now` / `deliver_later` 호출이
   `SilenceGate` 밖에 존재하면 테스트가 깨진다.
3. **소리 검사 테스트** — `new Audio(` / `<audio` / `AudioContext` 가
   종성 컨트롤러 한 파일 밖에 나타나면 테스트가 깨진다.

## 3. 데이터 모델

```
Sitting                      ← 앉음 한 자리. 남는 것은 날짜뿐이다.
  user
  mode:string       # sitting(타이머) | nothing(무위)
  sat_on:date       # 사용자 시간대 기준 날짜. 달이 이 날짜를 센다
  ended_at:datetime # nil 이면 앉는 중
  index [user_id, sat_on]
```

**길이도, 분도, 종성 여부도 저장하지 않는다.** 그것들은 그 자리의
설정이지 기록이 아니다. 길이는 `SittingLength` 값 객체가 쥐고 있고,
주소에만 실려 다니다 사라진다.

```ruby
# app/models/sitting_length.rb — 저장되지 않는다.
MINUTES = { "short" => 3, "tea" => 10, "incense" => 20, "long" => 30, "open" => nil }
```

`Sitting` 에 점수·품질·완주 여부로 읽힐 컬럼을 두지 않는다.
중간에 나가도 그것은 실패가 아니다 — `ended_at` 은 끝난 시각일 뿐,
`completed` 같은 이름을 쓰지 않고 시작과의 차를 재는 코드도 없다(제3조).
`test/models/sitting_test.rb` 가 컬럼 목록을 통째로 못박는다.

앉음은 스스로 잊힌다. 무위에는 정해진 끝이 없으므로, 네 시간이 지난
자리는 끝난 것으로 본다 — 그러지 않으면 게이트가 영영 침묵한다.

## 4. 앉음도 달을 채운다

M1의 달은 `Rest` 만 세었다. M2에서는 **그 날 쉼을 기록했거나 앉았으면
그 날은 1이다.**

```
phase = (최근 28일 중 쉼을 기록했거나 앉은 날의 수) / 28
```

- 앉음을 마쳤다고 `Rest` 를 자동으로 만들지 않는다. 분을 쉼의 길이
  이름으로 환산하는 일(제3조가 금한 일)을 하지 않기 위해서다.
  달이 두 곳을 함께 볼 뿐이다.
- 타이머든 무위든, 3분이든 30분이든, 그 날은 똑같이 1이다.
  **앉음 사이에도 위계가 없다.**
- 하루에 여러 번 앉아도 1이다.

## 5. 숫자 없이 시간을 보이는 법

진행 화면에 숫자·막대·퍼센트·남은 시간을 쓰지 않는다. 대신:

### 타이머 — **달이 차오른다.**

| 축 | 뜻 |
|---|---|
| 차오름 | 시작에 그믐(朔), 끝에 보름(望). 쌓인 빛이 앉은 만큼이다 |
| 숨 | 입정 직후 한 번 또렷이, 그 뒤로는 알아채기 어려울 만큼 완만히 |

- 「달의 자취」의 달은 날들을 모아 차오르고, 앉음의 달은 그 한
  자리에서 차오른다. **긴 호흡과 짧은 호흡이 같은 방향을 본다.**
  시간의 소진이 아니라 고요의 익어감이 이 앱의 문법이다.
- 도상 갱신은 **성기게**(5초에 한 번) 하되, 그 사이는 CSS 가 이어
  붙여 계단을 지운다. 초를 세는 느낌도, 뚝뚝 끊기는 움직임도 없다.
- **입정 응답**: 시작 직후 잠깐 달이 또렷이 한 번 숨 쉰다 —
  "시작되었다"는 확인. 그리고 한 줄이 떴다 사라진다:
  「달은 아주 천천히 차오른다. 지켜보지 않아도 된다.」
  문제는 속도가 아니라 기대였다. 지켜보라는 듯한 화면에 볼 것이
  없으면, 고장인지 진행인지 몰라 자리를 뜬다.
- `prefers-reduced-motion` 이면 숨을 멈추고 고요한 원으로 둔다.
- 길이가 `open`(정함 없이)이면 닿을 목표 시점이 없다. 아주 완만한
  고정 속도로 차오르다 보름에 닿으면 그대로 머문다 — 다시 이지러지지
  않는다. 재촉도 소진도 없다. 끝은 사용자가 정한다.
- 접근성: 스크린리더에게도 남은 시간을 숫자로 말하지 않는다.
  `aria-label` 은 "앉는 중" 하나. 보이는 사람도 모르는 것을
  들리는 사람에게만 알려주지 않는다 — 형평이 곧 원칙이다.

### 무위 — **달마저 잠든다.**

화면이 서서히 먹빛으로 잠기고, 그 뒤로는 아무것도 없다.
달이 없다. 숨이 없다. 진행이 없다. 끝을 알리지 않는다.

두 화면의 차이는 한눈에 분명하다: **타이머에는 달이 있고, 무위에는 없다.**

### 길이는 글자로 적는다

선택 화면에도 숫자를 쓰지 않는다. 「스물여드레」의 선례를 따른다.

| 값 | ko | en |
|---|---|---|
| short | 짧게 앉기 | a short sit |
| tea | 차 한 잔의 앉음 | a cup of tea |
| incense | 향 한 대의 앉음 | one stick of incense |
| long | 긴 앉음 | a long sit |
| open | 정함 없이 | open-ended |

향 한 대·차 한 잔은 시계 이전의 전통이 시간을 재던 단위다 — 숫자 없이
길이를 말하는 법을 전통이 이미 발명해 두었다. 쉼의 길이(한 호흡·잠깐·
한동안·오래·시간을 잊었다)와 낱말이 겹치지 않게 두어, 환산으로 읽힐
여지를 없앤다.

이렇게 하면 `spirit_test` 의 "어느 화면에도 숫자가 없다"를 **예외 없이**
지킬 수 있다. 예외를 하나 열면 다음 예외를 막을 근거가 없어진다.

## 6. 종성 (鐘聲)

- **시작종** 한 번, **마침종** 한 번. **중간은 무음이다** — 중간 종은
  남은 시간을 알려주는 장치이고, 그것은 숫자의 다른 이름이다.
- 무위에서는 기본으로 울리지 않는다. 켜면 **들어갈 때 한 번만.**
  마침종이 없는 이유는 무위에 정해진 끝이 없기 때문이다.
- 소리는 게이트를 통과해서만 난다. 재생 경로는 파일 하나
  (`bell_controller.js`)뿐이고, 그 밖의 어떤 코드도 소리를 내지 않는다.

### 음원 — 지금의 결정과 남은 일

`freesound` 에서 CC0 샘플을 받아 오는 일은 **로그인·API 키가 필요해
지금 자동으로 할 수 없다.** 라이선스 표기는 사람이 원문 페이지에서
확인해야 하는 일이기도 하다. 그래서 두 단계로 간다.

1. **지금**: 종성을 **브라우저에서 합성한다**(Web Audio).
   싱잉볼의 비조화 배음(1 : 2.76 : 5.40 : 8.93)을 겹치고 아주 살짝
   어긋난 두 벌을 더해 울림을 만든다. 파일 0바이트, 제3자 0,
   라이선스 문제 0 — 바깥을 부르지 않는다는 원칙에 가장 가깝다.
2. **나중**: 진짜 CC0 싱잉볼 파일을 받으면 `app/assets/sounds/` 에
   `bell-start.*` · `bell-end.*` 로 넣고 `docs/SOURCES.md` 에
   **원문 제목·출처 URL·라이선스·확인한 날짜**를 적는다.
   재생기는 **파일이 먼저다** — 파일이 있으면 그것으로 울고 없으면
   합성음으로 운다. 코드를 고치지 않고 갈아 끼워진다.

### 소리는 손짓 안에서 난다 — 실기에서 드러난 결함

두 겹의 결함이 있었고, 둘 다 고쳤다.

1. **컨트롤러가 아예 붙지 않았다.** 종성 컨트롤러가 `get context()` 를
   두었는데, 스티뮬러스의 `Controller` 는 생성자에서 `this.context` 를
   대입한다. 세터 없는 접근자에 대입하면 엄격 모드에서 `TypeError` 가
   나고 컨트롤러는 그대로 죽는다 — 종이 영영 울리지 않았다.
   (`silence_test` 가 이제 예약어를 가리는 일을 막는다.)
2. **깨어나지 않은 컨텍스트의 얼어붙은 시간선.** 오디오 컨텍스트를
   화면이 바뀐 뒤에 만들면 브라우저가 정지(suspended) 상태로 준다.
   정지된 컨텍스트의 `currentTime` 은 흐르지 않으므로, 거기 예약한
   소리는 나중에 무언가가 컨텍스트를 깨우는 순간 한꺼번에 울린다 —
   "한참 뒤에 울린다"의 정체다.

해법은 의례의 순서를 코드에 그대로 옮기는 것이다.
**죽비가 먼저, 입정이 다음.** 「앉는다」를 누르는 그 손짓 안에서
컨텍스트를 깨우고 시작종을 친다. 종이 울리는 동안 화면이 어두워진다.
깨어난 컨텍스트는 모듈 수준에 하나만 두어 Turbo 전환을 건너 살아남고,
마침종은 그것을 그대로 써서 지체 없이 울린다.
깨어 있지 않으면 예약하지 않는다 — 끝내 깨우지 못하면 그냥 조용한
것이지, 한참 뒤에 놀래키지 않는다.

**남은 일(후순위)**: 음색을 더 선명하고 맑게. 기본음 높이, 배음의
비율과 세기, 타건 순간의 짧은 잡음 성분을 손볼 여지가 있다.
실음원으로 갈아 끼우면 자연히 해결되는 문제이기도 하다.

품질 기준: 단순 사인파 금지. 기본음 · 약 2.7배 · 5.4배의 비조화 배음과
스무 초 이상의 긴 지수 감쇠. 마지막에 0으로 데려가는 완만한 기울기를
두어 여운을 뚝 끊지 않는다. `silence_test` 가 이 셋을 모두 검사한다.

문구가 없다. 숫자가 없다. 나가는 길 하나만 흐리게 둔다.

### (3) 무위 — `/ko/nothing`

```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│                                     │
│      아무것도 하지 않아도 된다.        │   잠시 뒤 흐려져 사라진다

```

문장이 사라진 뒤에는 아무것도 없다. 끝을 알리지 않는다.
나가는 길은 보이지 않지만 화면 어디를 눌러도 잠시 나타난다.

나가는 그 순간, 한 번만 조용히 묻는다.

```
┌─────────────────────────────────────┐
│                                     │
│        쉼으로 남기겠는가.             │
│                                     │
│           [ 남긴다 ]                 │
│                                     │
│          그냥 나간다                  │
└─────────────────────────────────────┘
```

남기면 「시간을 잊었다」가 미리 골라진 기록 화면으로 간다 —
무위는 정의상 재지 않은 시간이므로. 거절하면 흔적이 없다.
같은 자리를 다시 열어도 물음은 되풀이되지 않는다.

### (4) 앉음을 마친 뒤

M1의 「오늘 몫 끝」 화면과 같은 자리로 간다.

```
┌─────────────────────────────────────┐
│               ◑                     │
│                                     │
│        앉았다. 달이 조금 찼다.        │
│                                     │
│        오늘 몫은 끝났다. 이제 쉬어라.  │
└─────────────────────────────────────┘
```

무위에는 이 화면이 없다. 무위는 마치는 것이 아니라 그만두는 것이다.

## 10. 완료 기준

1. 앉기(손짓 안에서 시작종) → 달이 차오른다 → 마침종 → 「오늘 몫 끝」.
2. 무위 → 어두워진다 → 한 줄이 사라진다 → 끝까지 아무것도 없다.
3. 두 화면의 차이가 설명 없이 보인다(달의 있고 없음).
4. 앉는 중·무위 중·야간에 종성 외 어떤 소리도 나지 않는다.
5. 게이트를 우회하는 발송·재생 경로가 소스 트리에 **존재하지 않는다**(테스트).
6. 명상·무위 화면을 포함한 모든 화면에 숫자가 0개, 외부 호스트가 0건.
7. `spirit_test` 를 포함한 전 테스트 통과.

## 12. 승인 후 반영된 변경

네 갈래 모두 권장안으로 확정되었고, 아래가 덧붙었다.

1. **무위에 길이를 두지 않는다.** 들어가면 어둠뿐이고 나가는 것은
   사용자가 정한다. 종성을 켜면 들어갈 때 한 번만, 마침종은 없다.
   더하여 — **나가는 순간 "쉼으로 남길까"를 한 번만 조용히 묻는다.**
   남기면 `duration` 에 「시간을 잊었다」가 미리 골라진 기록 화면으로
   간다(무위는 정의상 재지 않은 시간이므로 데이터와 체험이 맞물린다).
   거절하면 흔적이 없다 — 자동 생성이 아니라 사용자가 남기는 것이다.
   물음이 되풀이되지 않도록 flash 로 한 번만 띄운다.

2. **달이 두 곳을 본다.** `MoonPhase` 가 쉼 기록과 앉음의 합집합으로
   그 날의 하나를 센다. 앉음 → `Rest` 자동 생성은 하지 않는다 —
   "향 한 대 = 한동안" 같은 환산표는 제3조가 금한 가짜 정밀도의
   부활이다. 더하여 — **`Sitting` 은 `sat_on`(날짜)만 남긴다.**
   분도, 길이 이름도, 종성 여부도 저장하지 않는다. 그것들은 그 자리의
   설정이지 기록이 아니므로 주소에만 실려 다닌다.
   오늘 화면의 물음도 조정한다: 그 날 쉼이나 앉음이 이미 있으면
   「오늘 쉬었는가」 대신 「오늘은 이미 고요했다. 더 남길 쉼이 있는가.」
   「오늘 몫은 끝났다」는 기록한 그 자리에서만 말한다 —
   나중에 다시 열었을 때 되풀이하면 그것은 조름이 된다.

3. **종성은 우선 합성음.** 조건 둘이 붙는다.
   (가) 단순 사인파 금지 — 비조화 배음(기본음 · 약 2.7배 · 5.4배)과
   스무 초 이상의 긴 지수 감쇠. 여운이 뚝 끊기면 실패다.
   (나) 교체 가능 구조 — 재생기는 **파일이 먼저다.**
   `app/assets/sounds/bell-start` · `bell-end` 가 있으면 그것으로 울고,
   없으면 합성음으로 운다. 라이선스 기록 규약은 `docs/SOURCES.md`.
   `silence_test` 가 여운 길이·배음의 비정수성·파일 우선을 검사한다.

4. **길이는 글자로, 그리고 쉼의 길이와 겹치지 않는 낱말로.**

   | 값 | ko | en |
   |---|---|---|
   | short | 짧게 앉기 | a short sit |
   | tea | 차 한 잔의 앉음 | a cup of tea |
   | incense | 향 한 대의 앉음 | one stick of incense |
   | long | 긴 앉음 | a long sit |
   | open | 정함 없이 | open-ended |

   향 한 대·차 한 잔은 시계 이전의 전통이 시간을 재던 단위다 —
   숫자 없이 길이를 말하는 법을 전통이 이미 발명해 두었다.
   `rests.durations`(한 호흡·잠깐·한동안·오래·시간을 잊었다)와 낱말이
   겹치지 않게 두어, 환산으로 읽힐 여지를 없앤다.
   분은 `SittingLength::MINUTES` 안에만 있고, 브라우저에 초로 한 번
   건네질 뿐이다. 화면·저장·스크린리더 어디에도 숫자가 없다.

5. **외부 스킬 정책**은 [CLAUDE.md](../CLAUDE.md) 에 적었다.
   핵심 기능(쉼·달·명상·무위·안내·화두)에는 외부 스킬을 쓰지 않는다.
