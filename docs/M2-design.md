# M2 설계 — 명상 타이머 · 무위의 시간 · 침묵 게이트

> This app is a raft. — 이 앱도 뗏목이다.
> 근거: [SPIRIT.md](../SPIRIT.md) · 앞선 마일스톤: [M1-design.md](M1-design.md)

## 1. 범위

포함: 침묵 게이트(단일 모듈·우회 불가), 명상 타이머, 무위의 시간,
종성(鐘聲), 앉음이 달을 채우는 규칙, 「쉼의 안내」 2·5장의 연결.

제외: 빈 일정 스케줄러(M3), 一字一心(M4), 화두·내보내기·PWA 마감(M5).
M1과 같이 **이 마일스톤에서도 앱이 먼저 보내는 알림은 하나도 없다.**
게이트는 보내기 위해서가 아니라 **막기 위해** 먼저 세운다.

## 2. 침묵 게이트 (제4조)

기능이 늘어난 뒤에 게이트를 세우면 이미 늦다. 소리와 메일이 아직
둘뿐인 지금 세운다.

### 2.1 유일한 기준

> **부르지 않았는데 오는 것만이 알림이다.**

| 갈래 | 뜻 | 게이트 판정 |
|---|---|---|
| `solicited` | 사용자가 방금 청한 응답 | 통과. 야간에도 통과 |
| `unsolicited` | 앱이 먼저 거는 말 | **언제나 차단.** 예외 경로 없음 |

비밀번호 재설정 편지는 `solicited`다 — 사용자의 물음에 대한 답이지
앱의 말 걸기가 아니다(SPIRIT 제4조 주석). 종성도 `solicited`다 —
사용자가 그 자리에서 켜고 시작한 소리다.

`unsolicited` 목록은 **비어 있다.** 앞으로도 비어 있는 것이 목표다.
목록에 무언가를 넣으려면 SPIRIT.md 개정이 먼저다.

### 2.2 모듈

```ruby
# app/models/silence_gate.rb
SilenceGate.allow?(kind, user:, at: Time.current)   # → true | false
SilenceGate.deliver(kind, user:) { ... }            # 통과할 때만 블록 실행
```

`kind` 는 게이트가 아는 이름만 받는다. 모르는 이름은 `ArgumentError` —
등록되지 않은 발신은 "조용히 통과"가 아니라 **터진다.**

```
KINDS = {
  password_reset: :solicited,   # 사용자가 청한 편지
  bell:           :solicited,   # 종성
}
```

### 2.3 침묵의 시각

야간·앉는 중·무위 중에는 **종성 외 일체 무음**이다.

```
야간   = 사용자 시간대 기준 22:00 – 07:00
앉는 중 = 끝나지 않은 Sitting 이 있다
```

`solicited` 라도 종성이 아닌 소리는 이 시각에 나가지 않는다.
(지금 소리는 종성뿐이므로 실효 규칙은 "언제나 종성뿐"이다.
규칙을 먼저 두는 이유는 소리가 하나 더 생기는 날을 위해서다.)

### 2.4 우회 불가의 강제

문서로만 막지 않는다. 세 겹으로 막는다.

1. **인터셉터** — `SilenceGate::Interceptor` 를 ActionMailer 에 등록한다.
   게이트가 찍은 표식이 없는 메일은 발송 직전에 `SilenceGate::Bypass`
   예외로 죽는다. 표식은 발송 전에 헤더에서 지운다.
2. **소스 검사 테스트** — `deliver_now` / `deliver_later` 호출이
   `SilenceGate` 밖에 존재하면 테스트가 깨진다.
3. **소리 검사 테스트** — `new Audio(` / `<audio` / `AudioContext` 가
   종성 컨트롤러 한 파일 밖에 나타나면 테스트가 깨진다.

## 3. 데이터 모델

```
Sitting                      ← 앉음 한 자리
  user
  mode:string       # sitting(타이머) | nothing(무위)
  length:string     # 타이머만: three|ten|twenty|thirty|open. 무위는 nil
  bell:boolean      # 종성 여부. 타이머 기본 켬, 무위 기본 끔
  started_on:date   # 사용자 시간대 기준 날짜 (달이 이 날짜를 센다)
  started_at:datetime
  ended_at:datetime # nil 이면 앉는 중
  index [user_id, started_on]
```

**분을 저장하지 않는다.** `length` 는 이름이고, 분은 코드 안의 상수다.

```ruby
LENGTHS = { three: 3, ten: 10, twenty: 20, thirty: 30, open: nil }  # 분
```

`Sitting` 에도 점수·품질·완주 여부로 읽힐 컬럼을 두지 않는다.
중간에 나가도 그것은 실패가 아니다 — `ended_at` 은 끝난 시각일 뿐,
`completed` 같은 이름을 쓰지 않는다(제3조).
`test/models/sitting_test.rb` 가 컬럼 목록을 통째로 못박는다.

## 4. 앉음도 달을 채운다

M1의 달은 `Rest` 만 세었다. M2에서는 **그 날 쉼을 기록했거나 앉았으면
그 날은 1이다.**

```
phase = (최근 28일 중 쉼을 기록했거나 앉은 날의 수) / 28
```

- 앉음을 마쳤다고 `Rest` 를 자동으로 만들지 않는다. 분을 쉼의 길이
  이름으로 환산하는 일(제3조가 금한 일)을 하지 않기 위해서다.
  달이 두 곳을 함께 볼 뿐이다.
- 타이머든 무위든, 3분이든 30분이든, 그 날은 똑같이 1이다.
  **앉음 사이에도 위계가 없다.**
- 하루에 여러 번 앉아도 1이다.

## 5. 숫자 없이 시간을 보이는 법

진행 화면에 숫자·막대·퍼센트·남은 시간을 쓰지 않는다. 대신:

### 타이머 — **달이 기운다. 그리고 숨 쉰다.**

| 축 | 뜻 |
|---|---|
| 기움 | 시작에 망(滿), 끝에 삭(朔). 남은 빛이 남은 시간이다 |
| 숨 | 열 호흡에 한 번꼴로 아주 느리게 밝아지고 어두워진다 |

- 「달의 자취」의 달은 날들을 모아 **차오르고**, 앉음의 달은 그 한
  자리에서 조용히 **기운다.** 두 방향이 서로를 설명한다.
- 도상 갱신은 **성기게**(5초에 한 번) 한다. 초를 세는 느낌을 없앤다.
- `prefers-reduced-motion` 이면 숨을 멈추고 고요한 원으로 둔다.
- 길이가 `open`(자유)이면 기울 것이 없다. 달은 그대로 숨만 쉬고,
  끝은 사용자가 정한다.
- 접근성: 스크린리더에게도 남은 시간을 숫자로 말하지 않는다.
  `aria-label` 은 "앉는 중" 하나. 보이는 사람도 모르는 것을
  들리는 사람에게만 알려주지 않는다 — 형평이 곧 원칙이다.

### 무위 — **달마저 잠든다.**

화면이 서서히 먹빛으로 잠기고, 그 뒤로는 아무것도 없다.
달이 없다. 숨이 없다. 진행이 없다. 끝을 알리지 않는다.

두 화면의 차이는 한눈에 분명하다: **타이머에는 달이 있고, 무위에는 없다.**

### 길이는 글자로 적는다

선택 화면에도 숫자를 쓰지 않는다. 「스물여드레」의 선례를 따른다.

| 값 | ko | en |
|---|---|---|
| three | 삼 분 | three minutes |
| ten | 십 분 | ten minutes |
| twenty | 이십 분 | twenty minutes |
| thirty | 삼십 분 | thirty minutes |
| open | 자유 | open |

이렇게 하면 `spirit_test` 의 "어느 화면에도 숫자가 없다"를 **예외 없이**
지킬 수 있다. 예외를 하나 열면 다음 예외를 막을 근거가 없어진다.

## 6. 종성 (鐘聲)

- **시작종** 한 번, **마침종** 한 번. **중간은 무음이다** — 중간 종은
  남은 시간을 알려주는 장치이고, 그것은 숫자의 다른 이름이다.
- 무위에서는 기본으로 울리지 않는다. 켜면 **들어갈 때 한 번만.**
  마침종이 없는 이유는 무위에 정해진 끝이 없기 때문이다.
- 소리는 게이트를 통과해서만 난다. 재생 경로는 파일 하나
  (`bell_controller.js`)뿐이고, 그 밖의 어떤 코드도 소리를 내지 않는다.

### 음원 — 지금의 결정과 남은 일

`freesound` 에서 CC0 샘플을 받아 오는 일은 **로그인·API 키가 필요해
지금 자동으로 할 수 없다.** 라이선스 표기는 사람이 원문 페이지에서
확인해야 하는 일이기도 하다. 그래서 두 단계로 간다.

1. **지금**: 종성을 **브라우저에서 합성한다**(Web Audio).
   싱잉볼의 비조화 배음(1 : 2.76 : 5.40 : 8.93)을 겹치고 아주 살짝
   어긋난 두 벌을 더해 울림을 만든다. 파일 0바이트, 제3자 0,
   라이선스 문제 0 — 바깥을 부르지 않는다는 원칙에 가장 가깝다.
2. **나중**: 진짜 CC0 싱잉볼 파일을 받으면 `app/assets/audio/` 에 넣고
   `docs/SOURCES.md` 에 **원문 제목·출처 URL·라이선스·확인한 날짜**를
   적는다. 게이트와 재생 경로는 그대로다. 바뀌는 것은 음원뿐이다.

## 10. 완료 기준

1. 앉기 → 시작종 → 달이 기운다 → 마침종 → 「오늘 몫 끝」 → 달이 찬다.
2. 무위 → 어두워진다 → 한 줄이 사라진다 → 끝까지 아무것도 없다.
3. 두 화면의 차이가 설명 없이 보인다(달의 있고 없음).
4. 앉는 중·무위 중·야간에 종성 외 어떤 소리도 나지 않는다.
5. 게이트를 우회하는 발송·재생 경로가 소스 트리에 **존재하지 않는다**(테스트).
6. 명상·무위 화면을 포함한 모든 화면에 숫자가 0개, 외부 호스트가 0건.
7. `spirit_test` 를 포함한 전 테스트 통과.

## 12. 승인이 필요한 갈래

1. **무위에 길이를 두지 않는다** (권장) — 길이를 고르는 순간 그것은
   과업이 되고, 끝을 기다리는 마음이 생긴다. 대안: 길이는 고르되
   화면에 아무것도 보이지 않게 한다.
2. **앉음을 `Rest` 로 자동 기록하지 않고 달이 두 곳을 본다** (권장) —
   분을 쉼의 길이 이름으로 환산하지 않기 위해서다.
3. **종성은 우선 합성음** — 진짜 CC0 파일을 주시면 갈아 끼운다(6절).
4. **길이 표기를 글자로** (삼 분 · 십 분 …) — 숫자 금지에 예외를
   만들지 않기 위해서다.
