# 소개 쪽 재료

> This app is a raft. — 이 앱도 뗏목이다.

소개 글(훗날 맨 이름 `fulltimezero.com` 에 설 것)에 쓸 **남의 말** 둘. 둘 다 인용이지
우리 말이 아니다. **앱 화면에는 쓰지 않는다** — 화면의 말은 전부 우리 것이거나
대조한 경의 말이다(`Citation`). 소개 글에 쓸 때도 출처를 곁에 둔다.

## 하나 — 샹파까규(Shangpa Kagyu)의 한 줄

> We do not focus on the accumulation of recitations to stop people from feeling
> guilty or feeling it's impossible to achieve anything on their path.

| | |
|---|---|
| 출처 | 샹파까규 홈 — https://shangpakagyu.org/ |
| 본 날 | 2026-10-08 |
| 왜 재료인가 | 「쌓지 않는다」를 전통 쪽이 제 입으로 말한 자리다. 염주를 세어 보이지 않는 이 앱의 결과 닿는다 |
| 조심할 것 | 그 교단의 말이지 우리 말이 아니다. 「그들도 그렇다」로 쓰지 「그들이 우리를 편든다」로 쓰지 않는다 |

## 둘 — 「portable monastery」

Plum Village 앱을 **「휴대용 수도원(portable monastery)」**이라 부른 표현.

| | |
|---|---|
| 출처 | **리뷰의 말이다. Plum Village 자신의 말이 아니다.** 어느 리뷰인지는 쓸 때 다시 찾아 적는다 |
| 본 날 | 2026-10-08 |
| 왜 재료인가 | 앱 하나가 「자리」가 될 수 있다는 말 — 이 앱의 전각 여섯 · 문 · 마당과 같은 결이다 |
| 조심할 것 | Plum Village 가 스스로 그렇게 부른 것처럼 쓰면 틀린다. 「누군가는 그 앱을 이렇게 불렀다」까지만 |

## 쓰지 않을 것

챌린지 · 연속 기록 · 평가 · 「하나 더」 — 소개 글에도 들이지 않는다(§1 · §2 · §6).
