# 조사 — 온라인 절 「산사」

> This app is a raft. — 이 앱도 뗏목이다.
> 적은 날: 2026-11-04 · 조사 기록이다. 설계가 아니다. 여기서 가져오기로 한 것은 `docs/NEXT.md` 13–16 에 할 일로만 올렸다.

## 1. 무엇인가

「산사」(sansatemple.com)는 브라우저에서 들어가는 온라인 절이다. 2026년 10월 말에 화제가 되었다.
아래는 보도와 소개글에서 모은 사실이다. 우리가 직접 재 본 값은 없다.

| | |
|---|---|
| 만든 이 | 개인 개발자 박진원(26). AI 로 만들었다. 불교 신자가 아니고, 취업 준비로 바빠 절에 쉬러 갈 틈이 없어 만들었다고 한다 |
| 기술 | Three.js 3D. 받는 자원이 약 6.3MB 이고, 그 가운데 보살상 glb 둘이 각 1.5MB 다 |
| 운영 | 방 100개 × 100명. 화면에 방 번호와 인원을 보여 준다. 몰리자 방석을 1만 개까지 늘렸다 |
| 말 | 채팅은 없다. 합장하면 상대에게 알림만 간다 — 「합석은 되는데 말은 못 걸어요」 |
| 할 수 있는 것 | 합장 · 절하기 · 목탁 · 염주(108 을 센다) · 향 · 염불 듣기 |
| 함께하는 때 | 매일 05:00 · 18:00 에 함께 예불한다 |
| 돈 | 공양미 · 복전함(개인 계좌). 서버비 부담으로 후원 기능이 한때 멈췄다 |
| 분석 | Google Analytics 와 Cloudflare 분석이 붙어 있다 |
| 규모 | 사흘에 60만 방문. 그 가운데 대만이 5만 |
| 그 뒤 | 같은 꼴의 복제품(온라인 성당 · 교회)이 나왔다 |

**가져올 것**

- **말 없는 동석** — 「합석은 되는데 말은 못 걸어요」. 곁에 누가 앉아 있다는 것만 안다. 우리는 거기서
  알림도 빼고, 수도 뺀다 → NEXT 13.
- **함께하는 때** — 같은 시각에 같은 소리를 듣는 것. 부르지 않고, 와 있는 사람에게만 → NEXT 14.
- **가벼움** — 설치도 가입도 없이 브라우저에서 바로. 우리 손님 자리와 같은 쪽이다. 6.3MB 가 아니어도
  이것은 된다.
- **zh-TW 수요** — 사흘에 대만 5만. 번역이 아니라 그 언어로 쓴 문장으로 → NEXT 15.
- **만든 이의 이야기** — 「쉬러 갈 틈이 없어 만들었다」가 사람을 움직였다. 우리도 /about 에 왜 만들었는지
  한 단락을 둘 수 있다(할 일로 올리지 않았다 — 쓸 사람이 정한다).

**가져오지 않을 것**

- **108 셈** — 세는 순간 쉼이 할당량이 된다(§3 · 제3조).
- **인원 표시** — 몇 명이 있는지는 비교의 시작이다(제5조, `comparing_test` 의 뜻).
- **계좌** — 개인 계좌 복전함. 돈이 오가는 자리는 이 앱의 핵심 기능에 두지 않는다(CLAUDE.md 외부 스킬 정책).
- **분석 스크립트** — GA · Cloudflare 분석. 제3자 요청이다(제6조).
- **3D 엔진** — 무게와 바깥 스크립트(importmap 은 저장소 안만). 깊이는 겹으로 낸다 → NEXT 16.

## 3. 경전의 근거 둘

- **MN 26 『성구경(Ariyapariyesana Sutta)』** — 비구들이 모이면 할 일은 둘이다: 법에 대한 이야기, 아니면
  성스러운 침묵(*ariyo tuṇhībhāvo*). 함께 있되 말하지 않는 것이 둘째 길로 이미 있다.
- **SN 45.2 『반(半)경(Upaḍḍha Sutta)』** — 좋은 벗(*kalyāṇamittatā*)은 청정한 삶의 절반이 아니라
  전부다. 곁에 누가 있다는 것 자체가 길의 일부다.

둘 다 근거일 뿐 화면의 경구가 아니다. 화면에 올리려면 원문 대조가 먼저다(`citation_test`).
