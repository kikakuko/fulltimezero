# 결 자물쇠

> 사용자가 배신당했다고 느낄 수 있으면 약속이다. 취향이 달라졌을 뿐이면 결이다.

> 자물쇠는 「하지 않음」을 지키고, 기능 테스트는 「함」을 지킨다.
>
> - **약속 자물쇠**(`test/locks/promise/`) — 앱이 하지 않겠다고 한 것. 풀면 안 된다.
> - **결 자물쇠**(`test/locks/form/`) — 지금 고른 모양. 방향을 틀면 푼다.
> - **기능 테스트**(`test/integration/` · `test/models/`) — 앱이 하기로 한 것.
>   깨지면 버그고, 푸는 게 아니라 고친다.

**여기 것은 방향을 틀면 풀 수 있다.** 다만 풀 때는 기능과 같은 커밋에 섞지 않고 따로
커밋해 까닭을 적는다(CLAUDE.md). 지금 이렇게 생겼다는 기록이지, 영원히 이래야 한다는
말이 아니다.

| 자물쇠 | 무엇 |
|---|---|
| `palette_test` `type_test` `component_test` | 밑색 열셋 · 명조 18px · 부품 다섯 |
| `daylight_test` `motion_test` `gate_light_test` `daily_door_test` | 하루의 때 · 움직임의 곡선 · 문의 빛 |
| `spirit_form_test` | 화면에 아라비아 숫자 · 이모지 · 느낌표가 없다. 문 넷의 자리. 달의 도상 |
| `images_test` `manifest_test` `dependency_test` | 그림 무게 · 아이콘 · 젬과 꾸러미의 수 |
| `search_gate_test` | 검색에 보일 것인가(기본 막음) — 보여 줄 때가 되면 푼다 |
| `elephant_parts_test` `elephant_flow_test` `elephant_form_test` `void_dispersal_test` | 코끼리의 결과 흩어짐 |
| `maitreya_test` `maitreya_flow_test` `pagoda_test` `pagoda_layout_test` `moon_phase_test` | 미륵 · 탑 · 달의 값 |
| `threshold_test` `compound_flow_test` `days_flow_test` `sitting_flow_test` `copying_flow_test` `rest_flow_test` `settings_flow_test` `abidings_form_test` | 각 화면의 짜임 |
| `verse_form_test` | 경의 말을 어떤 색으로 세우는가 |
| `languages_test` `abiding_test` `sutra_test` `greeting_test` `sitting_length_test` `user_test` | 언어와 자료의 결 |

새 자물쇠를 걸 때도 같은 물음으로 고른다 — **이것이 깨지면 사용자가 속았다고 느끼는가,
아니면 취향이 달라진 것인가.**
