# 약속 자물쇠

> 사용자가 배신당했다고 느낄 수 있으면 약속이다. 취향이 달라졌을 뿐이면 결이다.

> 자물쇠는 「하지 않음」을 지키고, 기능 테스트는 「함」을 지킨다.
>
> - **약속 자물쇠**(`test/locks/promise/`) — 앱이 하지 않겠다고 한 것. 풀면 안 된다.
> - **결 자물쇠**(`test/locks/form/`) — 지금 고른 모양. 방향을 틀면 푼다.
> - **기능 테스트**(`test/integration/` · `test/models/`) — 앱이 하기로 한 것.
>   깨지면 버그고, 푸는 게 아니라 고친다.

**여기 것은 풀지 않는다.** 방향이 바뀌어도, 디자인을 다시 해도, 급해도 풀지 않는다.
푸는 변경은 만든 사람에게 **먼저 묻는다**(CLAUDE.md).

여기 있는 것이 지키는 약속:

| 자물쇠 | 약속 |
|---|---|
| `silence_test` · `silence_gate_test` | 부르지 않은 알림은 없다. 게이트를 우회하는 경로가 코드에 없다 |
| `spirit_promise_test` | 바깥을 부르지 않는다. 알림이 새지 않는다. 사람을 재지 않는다(퍼센트 · 연속 · 분 · 층 · 남은 것). 가르치지 않는다. 인용에 출처가 있다 |
| `forgetting_test` | 지우면 다 지워진다 |
| `export_flow_test` · `export_test` | 내보내면 다 나온다(§7) |
| `session_test` | 세션에 접속 주소도 브라우저 정보도 남기지 않는다 |
| `rest_test` · `sitting_test` · `copying_test` | 판정하지 않는다 — 점수 · 등급 · 완주 칸이 생기면 깨진다 |
| `abidings_promise_test` | 앱이 자리를 정해 주지 않는다. 코끼리와 아홉 자리를 잇지 않는다. 고른 자리는 내보내기에 담긴다 |
| `elephant_promise_test` | 코끼리와 아홉 자리를 코드로 잇지 않는다. 쌓인 것은 무너지지 않는다 — 리셋이 없다 |
| `verse_promise_test` | 지은 말에 경의 이름을 붙이지 않는다. 인용에는 반드시 출전이 붙는다 |
| `importmap_test` | 바깥(CDN)을 부르지 않는다 — 스크립트는 저장소 안에서만 온다 |
| `guide_test` | 「쉼의 안내」는 가르치지 않는다. 인용에는 출처가 있다 |

새 자물쇠를 걸 때도 같은 물음으로 고른다 — **이것이 깨지면 사용자가 속았다고 느끼는가.**
